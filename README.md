# 🌩️ Nimbus Atlas

A sleek dark-themed app to explore countries and check their current weather in real time.

## Overview
Short paragraph: what the project does, what problem it solves.

## Features
- 🔍 Search any country by name
- 🌍 View flag, capital, population, region and currency
- ☁️ On-demand weather lookup for the capital city
- 🌙 Dark futuristic UI
- ⚡ No frameworks — pure HTML, CSS and JavaScript

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- REST Countries API
- Open-Meteo API

## How It Works
1. User searches for a country
2. App fetches country data from REST Countries API
3. User clicks "View Weather"
4. App fetches weather data using the country's capital coordinates
5. Data is rendered on screen

## Getting Started
### Prerequisites
- A modern browser
- VS Code + Live Server extension (recommended)

### Installation
​```bash
git clone https://github.com/seu-usuario/nimbus-atlas.git
cd nimbus-atlas
​```
Then open `index.html` with Live Server.

## APIs Used
- [REST Countries](https://restcountries.com) — country data, no auth required
- [Open-Meteo](https://open-meteo.com) — weather data, no auth required
